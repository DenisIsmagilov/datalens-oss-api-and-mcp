# Безопасность

`DL_API_TOKEN` и `MCP_AUTH_TOKEN` — полные права сервисного пользователя DataLens (всё, что умеет API: чтение, запись, delete, export). Это не per-user ACL.

- Не коммитьте `.env`.
- `MCP_AUTH_TOKEN` и `DL_API_TOKEN` — **разные** строки. Утечка MCP-токена не должна совпадать с догадкой про API-токен, но оба дают доступ к одним операциям через разные входы.
- Порты `8393` и `8394` не публикуйте в интернет без firewall / VPN. Минимум: только LAN.
- MCP не отдаёт клиенту `DL_API_TOKEN`; внутрь API ходит своим сервисным токеном.
- Тела create / `call_rpc` не логируются сервисом; не гоняйте реальные пароли источников через отладочные прокси.

Ротация: сменить значение в `.env`, перезапустить контейнер (`docker compose up -d`).
